# SoftwareAgent

**AI-Powered Software Installation, Compatibility & Repair Agent**

SoftwareAgent is a Windows-focused intelligent agent designed to simplify software installation, identify compatibility issues, diagnose failures and eventually perform verified repairs.

## Current Features

### 1. Windows Environment Scanner
- Windows OS and build detection
- CPU, RAM and storage detection
- Python, Node.js, Java and Git detection
- VS Code and WinGet detection
- GPU and graphics driver detection
- .NET runtime detection
- Visual C++ Redistributable detection
- DirectX registry detection
- Installed application inventory

### 2. Compatibility Intelligence Engine
- Docker Desktop compatibility evaluation
- Windows build and architecture checks
- Hardware virtualization checks
- WSL version and Windows feature checks
- Memory and storage evaluation
- Docker installation detection
- Docker Engine health checks
- Structured compatibility reports

## Status

Early development — Windows MVP.
